# Gyan Sarovar — Brahma Kumaris Digital Ashram

A free, **local-first**, **offline-ready** web application in a warm ivory, golden-cream, saffron-gold, and deep ruby-espresso Sanctuary design for **Atmas** (`BK [Name] Bhai` / `BK [Name] Bahan`).

All repository files are located directly in the **main root** (`index.html`, `styles.css`, `app.js`, `data.js`, `baba-portrait.png`, `sw.js`, `manifest.json`) for instant deployment to GitHub Pages.
